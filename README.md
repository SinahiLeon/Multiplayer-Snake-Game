
# Multiplayer Snake Game

A real-time multiplayer Snake game developed in C# using Blazor, networking, and MySQL as part of my Software Practice coursework at the University of Utah.

## Overview

This project implements a multiplayer version of the classic Snake game using a client-server architecture. Multiple players can connect to a shared game server, control their snakes, and interact within a synchronized game world.

The project focuses on network communication, real-time rendering, concurrency, and database integration.

## Technologies

- **C#** — Game logic, networking, and application development
- **Blazor** — Interactive web-based game interface
- **MySQL** — Persistent game data storage
- **.NET** — Application framework
- **Git** — Version control

## Features

- **Real-Time Multiplayer:** Supports multiple players connected to a shared game server.
- **Client-Server Communication:** Exchanges game-state information between clients and the server.
- **Interactive Gameplay:** Players control snakes within a shared game environment.
- **Canvas Rendering:** Renders the game world at approximately 50 frames per second.
- **Concurrent Game Updates:** Uses synchronization to manage shared game-state updates safely.
- **Database Integration:** Stores game-related information using MySQL.

## Technical Highlights

### Networking and Client-Server Architecture
Implemented network communication to support multiple clients interacting with a shared game world.

### Concurrency and Synchronization
Worked with thread-safe updates to maintain consistent game state while processing multiple player connections.

### Real-Time Rendering
Used Blazor and canvas-based rendering to display the game world and respond to player input.

### Database Persistence
Integrated MySQL to store game information beyond individual gameplay sessions.
